## Python Snake Game

A classic Snake game implemented with `pygame`.

### Features

- Score increases by 10 points every time the snake eats food.
- Pause and resume with `P`.
- Restart at any time with `R`.
- Keyboard movement with arrow keys or WASD.

### Setup

```bash
python -m pip install -r requirements.txt
```

### Run

```bash
python snake_game.py
```

### Controls

| Key | Action |
| --- | --- |
| Arrow keys / WASD | Move the snake |
| P | Pause or resume |
| R | Restart |
| Esc | Quit |
